# Git and GitHub Final Project

This repository was created as part of the **Getting Started with Git and GitHub** course final project.

## Project purpose

The purpose of this repository is to practice essential Git and GitHub workflows, including:

- Creating and managing a repository on GitHub
- Working with branches
- Adding and editing files
- Making commits with meaningful messages
- Using a license and contributing guidelines
- Cloning a repository and pushing local changes with Git commands

## Files in this repository

- `README.md` — Provides an overview of the project
- `LICENSE` — Specifies the open-source license for this project
- `CODE_OF_CONDUCT.md` — Describes expected community behavior
- `CONTRIBUTING.md` — Explains how contributors can participate
- `simple-interest.sh` — A shell script that calculates simple interest

## Simple-interest script

The `simple-interest.sh` script calculates simple interest using:

\[
\text{Simple Interest} = \frac{P \times T \times R}{100}
\]

Where:

- `P` is the principal amount
- `T` is the time period in years
- `R` is the annual rate of interest
